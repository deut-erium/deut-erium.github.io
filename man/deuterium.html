ManualDEUTERIUM(1)

deuterium(1) — manual

Name

deuterium — security blog, occasionally self-aware. This page is the user manual for the site itself.

Synopsis

deuterium [route] [?skin=id]

Browse by following links: every section (writeups, tutorials, ramblings) has its own home and archive, and the global archive lists every post ever published.

Append ?skin=id to any URL to preview a visual theme for that view, for example ?skin=key-exchange-kiosk. An unknown id falls back to your saved theme. The full list of themes is in the header menu labelled Theme; the choice is remembered per browser.

Themes are skins: colors, borders, and type only. Content and routes never change with the skin, and every theme carries the same text.

Options

theme dice The dice button in the top corner of every page rolls a random visual theme and remembers it. Roll until the blog hurts in a way you enjoy.

dark mode The moon/sun button toggles light and dark within the current theme. Before you press anything it follows your system preference. Once pressed, your choice wins.

See Also

archive(1) — every post on the blog, newest first, with the merged tag index.

writeups(1) — CTF challenge writeups by event and category. Flags stay unsolved here on purpose.
