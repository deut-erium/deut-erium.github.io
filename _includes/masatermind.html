<{% if include.panel %}{{ include.panel }}{% else %}h2{% endif %} class="mst-panel-title">Guesses and replies
    How guesses are chosen

    The game enumerates every candidate. Challenge keeps codes within the false-reply allowance, then chooses the one disagreeing with the fewest whole replies. Watch scores agreement with either whole replies or the exact count and total color overlap. Ties use numeric code order. Every failed guess is excluded.

    These rules explain past replies; they do not calculate which next question would reveal the most. The current game uses no Z3 download or probabilistic solver.

    Save or restore a session

    Saves include your secret and only update when you explicitly save. Download writes a file; Save in this browser keeps a local copy for this site. Game data is not sent to a server. Restore continues from the saved turn, with Watch paused and any unanswered guess still pending.

    Only an explicit save is available after reload. Reset does not delete your browser save.
