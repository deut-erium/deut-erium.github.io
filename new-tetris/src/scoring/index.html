Both game modes use the same score

Pick the same date and the daily game gives everyone the same pieces. It stops after 1,008 pieces, or when the blocks reach the top.

Endless play keeps going until the blocks reach the top. Both games use the same scoring rules.

Words used on this page

Piece mix
The pieces used to make a square. O4 means four O pieces. I2-J2 means two I pieces and two J pieces.
Way to build
A playable arrangement shown in the 4x4 or 6x6 catalog. The same pieces may fit together in several ways.
Board arrangement count
The number of geometric tilings with a piece mix. The 8x8 counts do not claim that every arrangement is reachable or easy to play.
Gold square
Every piece has the same type.
Silver square
Two or more piece types are used.
Clean split
A gap between two rows or two columns that runs across the whole square without cutting through a piece.
Shape bonus
Extra points when the pieces are harder to separate with clean splits.

A Spin Move scores when all of these are true:

  • Look one space up, down, left, and right from every block in the new piece. Ignore spaces occupied by that same piece, then count each remaining position once. Empty spaces and filled spaces count. All wall and floor touches together count as one position. The total must be at least four.
  • The piece cannot move one space left, right, up, or down.
  • A full row passes through the piece.
  • Placing the piece did not make a new square.

Clearing a square row can collect square value alongside the line award. Dropping faster, clearing rows on back-to-back turns, and level do not add points.

When a square counts

  • The whole 4x4, 6x6, or 8x8 area must be full.
  • Every piece must still have all four blocks inside that area.
  • The game looks for an 8x8 first, then 6x6, then 4x4.
  • Only one new square can be recognized when a piece lands.
  • If two squares of the same size are ready, the lower one wins. If they are level, the left one wins.
  • A 6x6 or 8x8 can grow around smaller squares you made earlier. Their uncollected value remains attached to their rows.

When square points are paid

Building a square does not add points immediately. Its total value is divided across its rows. Clear a row through the square to collect that row's share.

  • A 4x4 value is split across 4 rows, a 6x6 across 6 rows, and an 8x8 across 8 rows.
  • If the value does not divide evenly, some rows carry one extra point. Clearing every row still pays the exact total.
  • Clearing several square rows at once collects every share in those rows.
  • A Spin Move that breaks a square destroys any value still attached to it.

Example: a gold O4 has a total value of 2,500. Each of its four rows carries 625 points.

4x4 total value

Start with 1,000. Add 1,500 for gold. Add 250 for each piece type after the first. Add 1,000 when there is no clean split.

Look at every straight gap between the rows and columns. If at least one gap crosses the whole square without cutting a piece, there is no shape bonus. If every gap cuts through a piece, add 1,000.

Four O pieces with a clean split2,5001,000 to start + 1,500 for gold
Four T pieces with no clean split3,5001,000 to start + 1,500 for gold + 1,000 shape bonus

6x6 total value

Start with 2,500. Add 3,500 for gold. Add 500 for each piece type after the first. Then add the shape bonus below.

The game tries each gap between the rows and columns. When it finds a clean split, it splits there and repeats inside each smaller part. The largest part that cannot be split again sets the bonus.

The result can be a group of 1 to 6 pieces, or all 9 pieces. The complete 6x6 catalog has no result with a group of 7 or 8.

If all 9 stay together, the game finds the gap that cuts through the fewest pieces.

8x8 total value

Silver: 10,000. Gold: 20,000.

An 8x8 needs 16 complete pieces. It is much harder to finish than a 4x4 or 6x6, so it gets a much larger fixed value. The value is split across its eight rows.
